# 例: TeamLog プロダクト概要 — CEO / 経営層 業務フロー(架空 / プロダクト紹介)

このフォルダは、business-flow-architect の **TeamLog プロダクト紹介(CEO 視点)** のリファレンス実例です。

特定企業のヒアリング事例ではなく、**TeamLog プロダクトを CEO 業務フローとして説明する**ための業務記述書 + drawio + 課題分析 一式です。`templates/業務フロー図テンプレート.drawio` の構造に準拠(開始 → P-XXX → 終了 / 判断ひし形 / F-XXX / S-XXX / 矢印は source/target / ループバック=赤実線)。

## 用途

- 経営者向けプロダクト説明資料の業務フロー化リファレンス
- 「CEO 視点でプロダクトを使うとどうなるか」を スイムレーン + 判断ひし形 + ループバックを含む業務フロー図で表現したサンプル
- 11 プロセスのプロダクト紹介フロー構造のリファレンス

## 想定設定(架空)

| 項目 | 値 |
|---|---|
| 会社 | 株式会社グラフィックパス(架空) |
| 規模 | 全社 35 名、4 部署(エンジニア / デザイナー / ビジネス / コーポレート) |
| フェーズ | プレシリーズ A、TeamLog 導入後 3 ヶ月 |
| 経営会議 | 月 1 回(月初 第 2 月曜 10:00-12:00、社外取締役 + 投資家 参加) |
| TeamLog 連携 | Slack + Notion + Meet 字幕拡張 + GitHub + HubSpot |


## このサンプルが示す要素

- ✅ P-001〜P-011 の **11 プロセス**(朝のキャッチアップ → 経営会議準備 → 当日報告 → 即時 Q&A → 議事録)
- ✅ F-001〜F-004 の 4 ファイル
- ✅ S-001〜S-006 の 6 システム連携(うち S-006 は TeamLog MCP レーン)
- ✅ C-001〜C-006 の 6 課題発生ポイント(導入前の課題、全件 ✅ TeamLog で解決済み)
- ✅ **4 レーン構成**(CEO / 部署リード / TeamLog / 連携ツール)
- ✅ **判断ひし形 + ループバック**(P-008 → 質問あり → P-009/P-010 → 差戻し風で P-008 へ戻る)
